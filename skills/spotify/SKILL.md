# spotify

Плеер живёт на этой машине, поэтому им управляет AppleScript - тот же способ, которым Джарвис глушит музыку на время разговора (`~/.claude/jarvis/media.py`). Поиск по названию AppleScript не умеет, для него берётся открытый API Spotify.

## Команды

```bash
S=~/.claude/skills/spotify/spotify.sh

bash $S state                    # что играет: трек, исполнитель, альбом, громкость
bash $S play | pause | toggle
bash $S next | prev
bash $S vol 60                   # выставить
bash $S vol +10                  # прибавить
bash $S vol -10                  # убавить
bash $S shuffle on | off
bash $S find "kupla mahogany"    # найти трек и сразу включить
bash $S find-album "bonobo migration"
bash $S open "чиллаут"           # показать 8 вариантов, ничего не включая
```

Вызывать через `bash <путь>`, а не напрямую: бит `+x` через Obsidian Sync не доезжает на вторую машину.

## Что отвечать голосом

Скрипт печатает состояние построчно - пересказать одной фразой, не зачитывать поля:

- на `find` - молчать, ответ только текстом
- на `vol` - «сделал восемьдесят»
- на `state` - «играет Ishome, Ken Tavr»
- на `open` - назвать два-три первых варианта и спросить, какой
- на `playlist.py add` - молчать, если трек добавился

**Включённая музыка голосом не объявляется.** хозяин только что попросил музыку - и первое, что он слышит, это голос поверх неё. Что играет, он видит текстом в сессии и на экране плеера. Озвучивается только неудача: трек не нашёлся, плеер не запущен, включилось не то. Правило от 2026-08-23, его слова.

**Удачное добавление в плейлист голосом не объявляется.** хозяин слушает музыку, и голос поверх неё ради «добавил» мешает больше, чем помогает - результат он и так видит текстом в сессии. Озвучивается только неудача: плейлист с таким именем не нашёлся, трек не добавился, нет доступа. Правило от 2026-08-22, его слова.

Названия треков и исполнителей произносятся как есть, транслитерировать не надо - у голоса есть таблица латиницы, и на незнакомом слове он прочитает по буквам, что нормально.

## Ключи для поиска

Нужны два значения в Keychain:

```bash
security add-generic-password -U -s spotify-client-id     -a "$USER" -w '<client id>'
security add-generic-password -U -s spotify-client-secret -a "$USER" -w '<client secret>'
```

Берутся в панели разработчика Spotify: developer.spotify.com/dashboard, кнопка Create app. Dashboard прячется не в меню Documentation, а под именем пользователя справа вверху.

**Redirect URI обязателен и должен быть `http://127.0.0.1:8888/callback`.** Слово `localhost` Spotify не принимает с февраля 2025 - форма отвечает «this redirect URI is not secure». Само поле нам не нужно, оно понадобится только если когда-нибудь дойдём до личных плейлистов.

Регистрация и запросы бесплатны.

Токен приложения скрипт получает сам и кеширует в `~/.claude/jarvis/spotify_token` на час, права 600. Без ключей плеерные команды работают, поиск - нет.

## Свои плейлисты

```bash
P=~/.claude/skills/spotify/playlist.py

python3 $P list                                  свои плейлисты
python3 $P create "Имя" "описание"               создать приватный
python3 $P add "часть имени" spotify:track:...   добавить треки
python3 $P show "часть имени"                    что внутри
python3 $P uri "часть имени"                     uri, чтобы включить через spotify.sh
python3 $P like spotify:track:...                поставить сердечко
python3 $P liked                                 последние 20 сохранённых
python3 $P liked spotify:track:...               проверить, стоит ли сердечко
python3 $P unlike spotify:track:...              снять сердечко, только по одному
```

Работает на доступе от имени хозяина - `auth.py`, разовая процедура с браузером. Проверить: `python3 ~/.claude/skills/spotify/auth.py --check`. Токен обновляется сам, повторно авторизовываться не нужно.

Создаются приватными: плейлист, собранный голосом между делом, не должен молча появляться в профиле. Публичный - руками в приложении.

**Сердечки.** Право на изменение сохранённого (`user-library-modify`) выдано 23.08 по просьбе хозяина - без него «добавь в любимые» голосом не работает. Тем же правом можно обнулить всю библиотеку, поэтому `unlike` принимает ровно один трек за вызов, а массового снятия в коде нет. После добавления права нужна разовая переавторизация: `python3 ~/.claude/skills/spotify/auth.py`.

**Адреса API после миграции февраля 2026.** Приложениям в режиме разработки Spotify закрыл старые адреса, и они отдают 403:

- создание: `POST /me/playlists`, а не `/users/{id}/playlists`
- треки: `/playlists/{id}/items`, а не `/playlists/{id}/tracks`
- в ответе поле называется `item`, у старых ответов было `track`

Ошибка выглядит как «Forbidden» без объяснения, и легко принять её за нехватку прав - права при этом выданы правильно.

## Устройство

Три файла:

- `spotify.sh` - плеер и поиск: AppleScript плюс curl к API
- `pick.py` - разбор ответа поиска в строки «uri, название, исполнитель»
- `auth.py` - разовая авторизация от имени хозяина, хранение и обновление токена
- `playlist.py` - свои плейлисты: список, создание, добавление, просмотр
- `SKILL.md` - этот файл

Разбор вынесен отдельным файлом не для красоты: внутри `spotify.sh` он был написан
как `python3 - <<PY`, и heredoc забирал stdin под сам код - до `json.load` доходил
уже прочитанный скрипт вместо данных. Запрос к API при этом отвечал правильно,
поэтому ошибка выглядела как поломка поиска. Не возвращать код обратно в скрипт.

## Фокус окна

Скил не уводит экран в Spotify. Замер 22.08: единственная команда, которая поднимает
окно плеера, - проигрывание по ссылке, то есть `find` и `find-album`. Чтение состояния,
пауза, громкость и переключение трека фронтальное приложение не трогают вообще.

После проигрывания скил возвращает фокус тому, что было активно. Возврат отложен на
0.7 секунды: сразу он не работает - Spotify активируется чуть позже и перебивает.
Задержка правится через `JARVIS_SPOTIFY_FOCUS_DELAY`.

## Границы

- Только Mac1: AppleScript управляет приложением на этой машине, удалённо не работает.
- Приложение не запускается само. Оно закрыто - команды вернут «Spotify не запущен», и это правильно: тихий Mac должен оставаться тихим.
- Джарвис глушит музыку на время разговора своим механизмом (`media.py`) и возвращает как было. Этот скил про другое - про то, что играет, а не про паузу на время речи. Пересечения нет: `media.py` трогает только то, что сам поставил на паузу.
- `find` включает первый результат, не спрашивая. Нужен выбор - `open`.
